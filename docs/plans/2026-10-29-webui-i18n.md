# Web UI English and Simplified Chinese Implementation Plan

**Goal:** Add persistent English and Simplified Chinese interface selection, build the UI, and deploy to the existing private server.

**Architecture:** Use a small reactive Svelte locale store and source-text translation dictionaries without a new runtime dependency. Resolve browser language on first visit, persist explicit selection, fall back to English, and set the document language. Translate presentation strings only; preserve prompts, tool schemas, API contracts, and stored conversation content.

**Scope:** `tools/ui`, this plan, and deployment records. Preserve existing `linux-release` artifacts. No commits, pushes, upstream submissions, inference changes, or MCP performance changes.

## Execution

1. Inspect UI rendering, settings, test setup, and remote container configuration.
2. Add failing tests for locale selection, fallback, interpolation, and dictionary integrity; implement translation helpers and reactive persistence.
3. Add a language selector in settings. Convert interface strings and shared presentation metadata to reactive translations, without translating internal identifiers.
4. Verify focused unit tests, Svelte checks, changed-file formatting/lint, and production build. Inspect both languages in a browser and verify persistence and unchanged API behavior.
5. Inspect the existing Docker deployment. Back up its configuration, deploy versioned UI assets through `--path` where compatible, and retain a rollback path. Do not change model or inference arguments.
6. Verify the deployed page, API health, locale switching, and retained MCP configuration. Record exact verification and rollback instructions.
