# Interface languages

The Web UI supports English and Simplified Chinese. Open Settings > General > Language to switch immediately. The selection is stored in `LlamaUi.locale` in the current browser. On the first visit, supported browser language preferences are checked in order; unsupported preferences fall back to English.

The UI locale is independent of model prompts, conversation content, API fields, model identifiers, and MCP tool names and schemas. Unknown interface strings retain their English source text. Some less common messages and server-provided errors are not translated yet.

## Adding translations

- Source-text translations live in `src/lib/constants/locales/zh-CN.ts`.
- Components import `t` from `$lib/stores/locale.svelte` and call it while rendering, or inside `$derived`, so changes remain reactive.
- Use named parameters, for example `t('Default: {value}', { value: 42 })`, instead of concatenating translated fragments.
- Do not translate internal identifiers, user content, or model-facing definitions.
- HTML translations are only appropriate at existing trusted static help-text rendering sites. Never pass user or server content to `{@html}`.
- `scripts/localize-ui.mjs` is a one-time source migration helper, not a runtime DOM translator. Only reviewed dictionary entries are eligible for conversion.

## Verification

```sh
npm run test:unit -- --run tests/unit/i18n.test.ts
npm run check
npm run build
UI_TEST_URL=http://localhost:5173 node scripts/verify-i18n.mjs
```

The browser smoke test uses an installed Chrome browser. It checks initial Chinese selection, English selection persistence, switching back, the MCP dialog, mobile settings width, and runtime errors. Screenshots are written to `test-results/`.

## Private deployment

The deployment helper `scripts/deploy-i18n.sh` is specific to `/opt/llama-b11972` on the user's private server. It refuses to replace an existing backup or interrupt an active inference slot. It preserves the original startup script and container, adds a read-only static UI mount with `--path /webui`, and checks server health. It does not rebuild the inference binary.

Rollback after a successful deployment, when no inference request is active:

```sh
docker stop llama-b11972
docker rename llama-b11972 llama-b11972-i18n-rollback
docker rename llama-b11972-before-i18n-20261029 llama-b11972
docker start llama-b11972
cp /opt/llama-b11972/start.sh.before-i18n-20261029 /opt/llama-b11972/start.sh
```

Browser conversations and MCP configuration remain in browser storage on the same origin. This deployment does not clear that storage.
